# JangGame | جنگ‌گیم

نسخهٔ شخصی‌سازی‌شدهٔ بازی استراتژی آنلاین [OpenFront](https://github.com/openfrontio/OpenFrontIO)، با امکان بازی در شبکهٔ محلی (LAN).

## امکانات این نسخه

- انتخاب بین ۱۲ ژنرال با ویژگی‌های اختصاصی و چهار نوع قابلیت ویژه.
- تغییرات در ساخت‌وساز، ارتقای ساختمان‌ها، برد موشک‌ها و نمایش وضعیت واحدها.
- ساخت روم خصوصی و نمایش روم در فهرست عمومی سرور محلی.
- حالت مهمان برای LAN، بدون نیاز به سرویس حساب کاربری OpenFront.
- رفع خطای عمومی‌کردن روم: شناسهٔ مهمان در حالت LAN ثابت می‌ماند تا میزبان همچنان سازندهٔ روم شناخته شود.

## پیش‌نیازها

- Node.js نسخهٔ `24.15.0` یا بالاتر از شاخهٔ ۲۴ (کمتر از ۲۵).
- npm نسخهٔ `12.1.0` یا بالاتر از شاخهٔ ۱۲ (کمتر از ۱۳).
- Git و یک مرورگر جدید.

## نصب و اجرای محلی

```bash
git clone https://github.com/Ywnessalimi/JangGame.git
cd JangGame
npm run inst
npm run dev:host
```

برای نصب وابستگی‌ها از `npm run inst` استفاده کنید؛ این دستور نسخه‌های قفل‌شده را با `npm ci --ignore-scripts` نصب می‌کند.

بازی روی [http://localhost:9000](http://localhost:9000) اجرا می‌شود. دستور `dev:host` هم رابط بازی و هم سرور بازی را اجرا می‌کند.

در ویندوز می‌توانید از PowerShell هم اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-LAN.ps1
```

## بازی با دیگران در همان شبکه

۱. همهٔ دستگاه‌ها را به همان شبکه یا وای‌فای متصل کنید.
۲. بازی را با `npm run dev:host` اجرا کنید.
۳. آدرس IPv4 کامپیوتر میزبان را با `ipconfig` در ویندوز پیدا کنید.
۴. بازیکنان آدرس `http://<HOST-IP>:9000` را در مرورگر باز کنند؛ به‌جای `<HOST-IP>` آدرس کامپیوتر میزبان را قرار دهید. Vite نیز آدرس‌های شبکه را هنگام اجرا نمایش می‌دهد.

اگر فایروال ویندوز مانع اتصال شد، این دستور را یک‌بار در PowerShell با دسترسی Administrator اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Enable-LAN.ps1
```

این اسکریپت فقط پورت TCP شمارهٔ `9000` را برای شبکه‌های **Private** و دستگاه‌های همان زیرشبکه باز می‌کند. پورت‌های داخلی `3000`، `3001` و `3002` از طریق سرور رابط پروکسی می‌شوند. میزبان باید روشن و متصل به شبکه بماند. اگر روتر دسترسی دستگاه‌ها به یکدیگر را مسدود کرده باشد (Client/AP Isolation)، باید آن تنظیم شبکه بررسی شود.

## ساخت روم پابلیک

از **CREATE LOBBY** یک روم بسازید، **PUBLIC** را انتخاب کنید و زمان شروع و تعداد بازیکنان را مشخص کنید. با **LIST LOBBY** روم در فهرست عمومی همین سرور نمایش داده می‌شود. تنظیمات روم پس از عمومی‌شدن قفل می‌شوند.

«پابلیک» در این حالت یعنی قابل مشاهده برای کاربران متصل به سرور شما؛ روم به فهرست سرور رسمی OpenFront اضافه نمی‌شود. ورود به حساب، فروشگاه و قابلیت‌های وابسته به API اختصاصی OpenFront در حالت مهمان محلی در دسترس نیستند. حالت `dev:host` برای اجرای محلی و توسعه است؛ راه‌اندازی یک سرویس اینترنتی نیازمند پیکربندی جداگانه است.

## توسعه و آزمون

```bash
npm run dev
npm run typecheck
npm test
```

آزمون‌های مرتبط با تغییرات این نسخه:

```bash
npx vitest run --project node tests/Generals.test.ts
npx vitest run --project client tests/client/GeneralHUD.test.ts tests/client/ControlPanelAttackRatio.test.ts tests/client/AuthRefreshFailure.test.ts
```

برای جزئیات ساختار پروژه و دستورهای اصلی، [راهنمای OpenFront](README-UPSTREAM.md) را ببینید. کد رابط در `src/client`، سرور در `src/server` و موتور بازی در `packages/engine` قرار دارد.
